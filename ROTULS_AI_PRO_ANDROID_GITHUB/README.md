# ROTUL'S AI PRO — Android GitHub Actions

Project Android berbasis Capacitor. UI web dipertahankan dari versi Mac V4 dan dibungkus sebagai Android.

## Build APK tanpa Android Studio
1. Upload isi project ini ke repository GitHub.
2. Pastikan GitHub Actions diizinkan pada repository.
3. Push/commit ke branch `main` atau jalankan workflow manual dari tab Actions.
4. Buka workflow **Build ROTUL'S AI PRO APK**.
5. Setelah selesai, buka **Artifacts** dan download `rotuls-ai-pro-debug-apk`.

API key OpenRouter dimasukkan dari halaman Pengaturan aplikasi dan disimpan lokal di perangkat.
